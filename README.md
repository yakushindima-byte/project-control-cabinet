# PROJECT CONTROL PRO — сайт и личный кабинет

- `/` — демо на примере компании (как раньше), кнопка «Войти в кабинет».
- `/login.html` — вход, регистрация по коду доступа, приглашение сотрудника.
- `/app.html` — личный кабинет: все листы, данные компании хранятся на сервере, сотрудники работают вместе.
- `/admin.html` — ваша админка: коды доступа, клиенты, сроки, сброс паролей.
- `/privacy.html` — политика обработки персональных данных (заполните поля в квадратных скобках).

Продажи — на Boosty. После оплаты вы создаёте в админке код и отправляете покупателю.
Код на N дней подходит и для регистрации нового кабинета, и для продления существующего.

## Запуск в Timeweb Cloud

1. **База данных.** «Базы данных» → создать PostgreSQL в том же регионе. Включите резервные копии.
   Из карточки базы понадобятся: хост, порт, пользователь, пароль, имя базы.
2. **Приложение.** App Platform → «Создать» → тип Backend → Express (Node.js 22) → этот репозиторий, ветка `main`.
   Команда запуска — `npm run start` (по умолчанию). Путь проверки состояния — `/health`.
3. **Переменные** (в настройках приложения): `PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`,
   `ADMIN_PASSWORD` (не короче 10 символов). Если в настройках есть поле порта — `8080`.
   Если в логах ошибка про SSL при подключении к базе — добавьте `PGSSL=1`.
4. Откройте технический адрес приложения: демо, `/login.html`, `/admin.html`. Таблицы в базе создаются сами при первом запуске.
5. **Домен.** Уберите `projectcontrol.pro` из старого приложения со статическим демо и привяжите к новому, выпустите SSL.

## Оплата на сайте (Т-Банк)

1. В Т-Бизнесе: «Интернет-эквайринг» → терминал. Возьмите **Terminal Key** и **пароль** терминала.
2. В переменных приложения: `TBANK_TERMINAL_KEY`, `TBANK_PASSWORD`, `PLANS` (например `30:990,365:9900:Год`), `SITE_URL=https://projectcontrol.pro`.
3. Если чеки печатает онлайн-касса Т-Банка — `TBANK_RECEIPT=1` и `TBANK_TAXATION` под вашу систему налогообложения.
4. В настройках терминала Т-Банка укажите адрес уведомлений `https://projectcontrol.pro/api/pay/notify`
   (сервер и так передаёт его в каждом платеже).
5. Сначала тестовый терминал (ключ с DEMO): проведите тестовые платежи картами из документации Т-Банка.
   Потом замените ключ и пароль на боевые.

Новый покупатель: projectcontrol.pro/login.html#buy → тариф → оплата → кабинет создаётся сам, вход выполняется сам.
Продление: в кабинете «Команда и доступ» → кнопка тарифа. Все оплаты видны в админке.

## Обновление

Загрузите изменённые файлы в репозиторий — Timeweb пересоберёт приложение. Данные клиентов в базе не затрагиваются.

## Локальный запуск

```
npm install
PGHOST=localhost PGUSER=... PGPASSWORD=... PGDATABASE=... ADMIN_PASSWORD=... npm start
```
